### 经验补充
- `add_p17.py` 把**全部断言前置到写文件之前**（assert 锚点唯一性 + assert 结果状态），这个模式比 p16 时「先写后 grep 发现 active=2 再补救」更稳，建议后续沿用。
- 备份文件放在**仓库外父目录**时，`rm -f` 会被 safe-delete 策略拦截（路径拼接错误导致 trash 失败）。无害但会刷一屏 stderr；下次备份直接放系统 temp 或干脆不备份（有 git 兜底）。
- `git push` 仍会超出前台超时被自动转后台（本次 task_id xANVVO），属正常，用 TaskOutput 取结果即可。
