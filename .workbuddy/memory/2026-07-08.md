## 第1轮反馈修复（2026-07-08 11:25 收到手机截图）

### 问题 A：Header 右上角的「日历/下载PDF」按钮漂在中间
- **根因**：mobile CSS 用 `position: static; align-self: flex-end; margin-top: -34px` 这种"假定位"hack，在 column flex 里不可靠
- **修复**：`.header` 加 `position: relative; padding-top: 50px`（留 50px 给 actions）；`.header-actions` 改 `position: absolute; top: 12px; right: 16px; margin: 0`
- **教训**：永远不要用 `margin-top: 负值` 来模拟定位，直接用 absolute

### 问题 B：月份下拉点开看不到期次列表
- **根因**：mobile `.tabs` 用 `overflow-x: auto` 横向滚动，**会裁剪内部所有 absolute 定位的子元素**。`.period-dropdown` 是 `position: absolute; z-index: 30`，被 `.tabs` 滚动容器裁了所以看不到
- **修复**：
  1. mobile `.tabs` 改 `flex-wrap: wrap; overflow: visible`（让月份按钮换行，不再横向滚动）
  2. `.month-group` 提 z-index 到 50
  3. `.period-dropdown` 提 z-index 到 100
  4. `.month-btn` 缩小 padding（6px 10px）和字号（11px），让一行能放 3 个月份按钮
- **教训**：`overflow: auto/scroll` 会创建独立的 formatting context，**会裁剪 absolute 子元素**。下拉/弹窗类组件的父容器永远不要 overflow:auto
