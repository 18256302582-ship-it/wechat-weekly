## 移动端响应式适配（feat: 移动端响应式适配 ≤768px）

**提交**：`79b1612 feat: 移动端响应式适配 (≤768px)`，推送 `fdd52f5..79b1612 main -> main`

### 根因
index.html 完全没有 `@media (max-width: ...)` 断点，只有 `@media print`。PC 端样式写好后没做手机端适配，手机只能按比例缩小渲染。

### 改动
在 build_html.js 的 `<style>` 中、@media print 之前插入 `@media (max-width: 768px) { ... }` 块。

**规则数**：53 条；**覆盖 class**：45 个（header / header-actions / header-text / header-update / header-meta / update-cur / update-next / tabs / tab-btn / month-btn / period-dropdown / cal-wrap / cal-nav / cal-month-label / cal-legend / cal-grid / cal-cell / cal-day-header / day-num / week-label / search-bar / search-input-wrap / filter-tags / filter-tag / search-result-count / deadline-bar / deadline-label / deadline-chip / deadline-close / container / overview-table / dim-cell / dim-block / dim-header / dim-icon / dim-title-text / dim-count / dim-body / item / item-title / link-btn / alert-badge / share-btn / footer / footer-update / footer-next / footer-credit）

### 关键设计点
1. **Header 改 stack**：`.header` 改 `flex-direction: column; align-items: flex-start; padding: 20px 16px 16px`，`.header-actions` 移出绝对定位，浮在右上
2. **Tabs 横向滚动**：`.tabs` 改 `flex-wrap: nowrap; overflow-x: auto; -webkit-overflow-scrolling: touch;`，隐藏滚动条（`::-webkit-scrollbar { display: none }`）
3. **下拉菜单适配**：`.period-dropdown` 改 `right: 0; left: auto; min-width: 160px; max-height: 70vh; overflow-y: auto`，避免溢出屏幕
4. **Calendar 全面收紧**：padding 40px→12px、min-height 36px→30px、字号 12px→10px
5. **Search 100% 宽**：`.search-input-wrap` 去掉 max-width 限制，`.search-result-count` 强制换行
6. **Items**：`.link-btn` 改 `display: block; width: fit-content`，按钮单独成行、不会被挤到右边
7. **Footer 单列**：`.footer-update` 改 `flex-direction: column`
