## Tab 期次栏改为「按月分组下拉选择器」（本次执行）
- **问题**：用户反馈"小 tag 越来越多也占位"。原 Tab 栏为 12 个期次按钮（每周一期），随期次累积无限膨胀
- **方案**：用户提议"tag 显示月份，点击月份下拉选周期"。实现后 12 期 → 仅 4 个月标签（2026年3/4/5/6月），点击月份展开该月所有周期
- **实现要点**：
  - 删除硬编码的 12 个 `<button class="tab-btn">`，改为空容器 `<div class="tabs" id="tabsRoot"></div>`
  - 新增 `renderTabs()`：从 `PERIODS` 数组按 `start` 的年月分组，动态生成"月按钮 + 下拉周期列表"
  - 月按钮点击展开/收起（切 `.open` 类）；周期选项点击调用 `selectPeriod(id)` → `switchTab(null,id)`
  - `switchTab` 重构：切换内容区 `.active`、同步 `.period-opt` 高亮、展开所属月并收起其他月
  - 日历日期点击、截止日 chip 点击原通过 `.tab-btn` 查找按钮，改为直接 `switchTab(null, period.id)`
  - **⚠️ 关键坑**：`build_html.js` 用模板字符串嵌入整段 `<script>`，若在 `renderTabs` 里用字符串拼接 `onclick="selectPeriod(\'p9\')"` 会被模板转义破坏 → 浏览器 JS 报 "Unexpected string"。**必须用纯 DOM API（createElement + .onclick）构建，避免引号转义**。改用 DOM 版后正常。

- **经验**：在 build_html.js 模板内写内联 onclick 带引号极易被转义破坏，统一用 DOM API 或事件委托
